# CSAT Analytics Dashboard (Power BI Project)

## 📌 Project Overview
The goal of this project is to analyze customer satisfaction (CSAT) data, identify patterns, trends, and actionable insights to optimize customer service processes, improve response times, and enhance the overall customer experience.

## 📊 Dataset Information
* **Total Records:** 32,942 customer service calls
* **Total Features:** 12 columns
* **Key Attributes:** `customer_name`, `sentiment`, `csat_score`, `call_timestamp`, `Call_Day`, `reason`, `city`, `state`, `channel`, `response_time`, `call duration in minutes`, and `call_center`.

## 🛠️ Tasks & Visualizations Implemented
* Connected Power BI to the MySQL database (`projects.datamites.com`) using live credentials.
* **Line Chart:** Analyzed call volume trends over time.
* **Doughnut Chart:** Evaluated distribution across different communication channels.
* **Map Visualization:** Geographically tracked customer calls across various states.
* **Column Chart:** Identified primary reasons for customer calls (e.g., questions, complaints, requests).
* **Bar Chart:** Measured response times for customer inquiries.
